# Analyzing Historical Stock and Revenue Data

## Project Overview

This project analyzes historical stock prices and quarterly revenue data for **Tesla (TSLA)** and **GameStop (GME)**.

The goal is to collect financial data, clean and process it, and visualize the relationship between stock prices and company revenue over time.

## Project Objectives

- Extract historical stock price data using Yahoo Finance (`yfinance`).
- Collect quarterly revenue data through web scraping.
- Clean and process financial datasets using Pandas.
- Visualize historical stock prices and company revenue.
- Compare stock price trends with revenue performance.

## Tools & Technologies

- Python
- Pandas
- yfinance
- BeautifulSoup
- Requests
- Matplotlib

## Project Structure

`Analyzing_historical_stock_and_revenue.ipynb`

The Jupyter Notebook contains the complete analysis, including data extraction, cleaning, and visualization.

## Visualizations

The project includes separate visualizations for Tesla and GameStop, showing:

- Historical share prices.
- Historical quarterly revenue.

## Conclusion

This project provides practical experience in financial data analysis, web scraping, data cleaning, and visualization using Python.
